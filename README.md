# Dashboard SPA Responsivo - Cloud Monitor

##  Restricción Técnica Cumplida
El proyecto fue desarrollado utilizando exclusivamente:
* HTML5 Semántico
* CSS Nativo (CSS Grid y Flexbox)
* JavaScript Vanilla
* *No se utilizaron frameworks prefabricados como Bootstrap o Tailwind.*

## 🛠️ Instalación y Arranque Local

Para ejecutarlo localmente:
1. Descarga este repositorio en tu computadora.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador web predeterminado.

## 📱 Características Principales
* **Arquitectura Mobile-First:** Reglas base para celular escaladas progresivamente a escritorio.
* **Layout Moderno:** Maquetación bidimensional con Bento Grid Layout y unidimensional con Flexbox.
* **Modo Oscuro Nativo:** Integrado con variables CSS (`:root`) y botón de alternancia.
* **Interacciones Clave:** Ventana modal nativa (`<dialog>`) y Drawer (panel deslizante) para configuraciones.
* **Manejo de Estados:** Controles rigurosos para los estados Default, Hover, Focus, Disabled y Loading.
